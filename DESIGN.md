# Typography and visual identity

The portfolio at heyabhilash.com is the visual reference. Preserve its charcoal
surfaces, blue accents, direct copy, flat separators, and uncluttered layout.

UI and reading type: `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.
Code and numeric identifiers: `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`.
Body weight is 400, controls and labels 600, section headings 700, page titles
and wordmarks 750. Headings use tracking around -0.035em and 1.15 line height;
prose uses 1.65 line height and a measure of 45–75ch. Dense app controls can keep
compact role sizes, while phone text inputs stay at least 16px.

Use the same stack across the portfolio, Orbit, Cadence, and Aftermath. Do not
add a display face or a font CDN. MathML equations, mathematical input labels,
and music engraving retain their specialist typography. Keep browser zoom and
keyboard focus intact. Refresh previews and documentation captures after
visible UI changes.
